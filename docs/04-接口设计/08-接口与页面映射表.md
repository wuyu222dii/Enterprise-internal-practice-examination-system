## 6. 正式考试核心链路（E2E-06 详表）

| 步骤 | 接口 | 页面 | 关键字段 |
| --- | --- | --- | --- |
| 1. 查看任务 | `GET /exams/tasks` | MP-09, EX-02 | lifecycle, examCode |
| 2. 任务详情 | `GET /exams/{id}` | MP-10, EX-03 | 脱敏规则摘要 |
| 3. 幂等开卷 | `POST /exams/{id}/attempts` + Idempotency-Key | EX-03, EX-04 | attemptId, paper, timing |
| 4. 恢复/计时 | `GET /attempts/{id}` | EX-04 | serverNow, expiresAt |
| 5. 逐题保存 | `PUT /attempts/{id}/answers/{itemId}` | EX-04 | answerVersion → confirmedVersion |
| 6. 交卷 | `POST /attempts/{id}/submit` + Idempotency-Key | EX-04 | attemptStatus |
| 7. 受控结果 | `GET /attempts/{id}/result` | EX-05, MP-11 | ResultVisibility |
