## 2. 练习

### 2.1 GET /practice/banks

返回 `practiceEnabled=true` 且题库 `status=active` 的列表。

### 2.2 POST /practice/sessions

**请求：**

```json
{
  "questionBankId": "bank_xxx",
  "mode": "sequential",
  "scope": {
    "categoryId": null,
    "knowledgePointId": null
  },
  "questionCount": 20
}
```

**mode：** `sequential`（顺序续做）| `random` | `targeted` | `wrongBook`。

**questionCount：** 随机/专项仅允许 `10` | `20` | `50`；错题模式不超过 50，可等于待练总数。

**约束（FR-PRA-02）：** 全模式最多一场进行中练习；存在时返回 `409 PRA_SESSION_ALREADY_ACTIVE` 并附带 `activeSessionId` 供恢复。

### 2.3 POST /practice/sessions/{id}/answers

逐题提交，**立即反馈**正误、标准答案与解析（与正式考试不同）。

**请求：**

```json
{
  "questionVersionId": "qv_xxx",
  "answer": ["A"]
}
```

**响应：**

```json
{
  "isCorrect": false,
  "standardAnswer": ["B"],
  "explanation": "...",
  "wrongBookStatus": "pending"
}
```

答错进入待练；任一日常练习答对一次移出待练（FR-PRA-04）。

### 2.4 GET /practice/wrong-book

分页返回待练错题；支持按题库筛选。

## 3. 模拟考试

### 3.1 POST /mock/attempts

**请求头：** `Idempotency-Key`

**请求：**

```json
{
  "questionBankId": "bank_xxx",
  "questionCount": 20,
  "durationMinutes": 60
}
```

`questionCount`：`10` | `20` | `50`；`durationMinutes`：10–180。

**响应 `data`：**

```json
{
  "attemptId": "mock_xxx",
  "status": "inProgress",
  "paper": {
    "items": [
      {
        "itemId": "item_1",
        "order": 1,
        "questionVersionId": "qv_xxx",
        "score": 2,
        "type": "singleChoice",
        "stem": "...",
        "options": []
      }
    ]
  },
  "timing": {
    "startedAt": "2026-08-30T12:00:00Z",
    "expiresAt": "2026-08-30T13:00:00Z",
    "remainingSeconds": 3600
  }
}
```

作答中**不返回**标准答案与解析（FR-SIM-02）。重复开卷返回原尝试与固定试卷。

### 3.2 PUT /mock/attempts/{id}/answers/{itemId}

与正式考试相同的版本化保存语义（`answerVersion` 单调递增）。

### 3.3 POST /mock/attempts/{id}/submit

**请求头：** `Idempotency-Key`

幂等提交；客观题自动评分；返回 `MockResult` 或 `submitting` 中间态。

### 3.4 POST /mock/attempts/{id}/abandon

二次确认后放弃；与 submit/timeout **争夺唯一终结权**（FR-SIM-04）。

- 放弃成功：保留已答记录，不评分，释放进行中名额
- 若 submit 已先取得终结权，返回同一 `MockResult` 或 `submitting` 态

### 3.5 GET /mock/attempts/{id}/result

提交后完整复盘（得分、错题、解析）；放弃记录无 `MockResult`，返回 `status=abandoned`。

## 4. 进行中会话约束

| 类型 | 规则 |
| --- | --- |
| 练习 | 最多 1 场进行中 |
| 模拟 | 最多 1 场进行中 |
| 与正式考试 | 互不影响（不同端/域） |

---

## 5. 错误码

| code | 说明 |
| --- | --- |
| `PRA_SESSION_ALREADY_ACTIVE` | 已有进行中练习 |
| `PRA_BANK_NOT_OPEN` | 题库未开放练习 |
| `PRA_INVALID_QUESTION_COUNT` | 题量不合法 |
| `SIM_ATTEMPT_ALREADY_ACTIVE` | 已有进行中模拟 |
| `SIM_BANK_NOT_OPEN` | 题库未开放模拟 |
| `SIM_ALREADY_TERMINATED` | 模拟已终结 |
| `SIM_DURATION_OUT_OF_RANGE` | 时长不在 10–180 分钟 |
