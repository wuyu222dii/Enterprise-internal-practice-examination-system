## 2. 部门

### 2.1 GET /departments

返回部门树或扁平列表（`?format=tree|flat`）。

**部门节点：**

```json
{
  "id": "dept_xxx",
  "name": "研发中心",
  "parentId": "dept_root",
  "path": "/总公司/研发中心",
  "status": "active",
  "employeeCount": 42,
  "children": []
}
```

### 2.2 POST /departments

**请求：**

```json
{
  "name": "质量部",
  "parentId": "dept_root"
}
```

同一父节点下名称唯一；违反返回 `ORG_DEPARTMENT_NAME_DUPLICATE`（422）。

### 2.3 PATCH /departments/{id}

支持改名、移动父节点、停用。

**停用约束：**

- 存在下级部门 → `ORG_DEPARTMENT_HAS_CHILDREN`
- 存在在职员工 → `ORG_DEPARTMENT_HAS_EMPLOYEES`
- 移动导致环 → `ORG_DEPARTMENT_CYCLE`

MVP 不物理删除部门。

## 3. 员工

### 3.1 GET /employees

分页查询；支持 `departmentId`、`status`、`keyword`（工号/姓名）筛选。

**员工摘要：**

```json
{
  "id": "emp_xxx",
  "employeeNo": "E10001",
  "displayName": "张三",
  "departmentPath": "/总公司/研发中心",
  "phoneMasked": "138****8000",
  "status": "active",
  "isAdmin": false,
  "hasOutageDisposition": false
}
```

### 3.2 POST /employees

手工建档。

**请求：**

```json
{
  "employeeNo": "E10002",
  "displayName": "李四",
  "departmentPath": "/总公司/研发中心",
  "phone": "13800138001"
}
```

**响应 `data`：**

```json
{
  "employee": { },
  "temporaryPassword": "Xk9#mP2!",
  "credentialBatchId": null
}
```

`temporaryPassword` **仅在本响应出现一次**。

### 3.3 POST /employees/import

`multipart/form-data` 上传员工 Excel。

**响应：** 创建 `ImportJob` 风格任务或直接返回行级结果（与导题任务分离域，结构类似）：

```json
{
  "batchId": "cb_xxx",
  "importedCount": 98,
  "skippedCount": 2,
  "skippedRows": [
    { "row": 5, "reason": "ORG_DUPLICATE_EMPLOYEE_NO" }
  ],
  "credentialBatchId": "cred_xxx"
}
```

重复工号、手机号或无效部门路径的行跳过，不覆盖旧档案。

### 3.4 PATCH /employees/{id}

可更新：`displayName`、`departmentPath`、`phone`、`status`（`active` | `disabled`）。

停用员工（`status=disabled`）立即撤销会话（FR-AUTH-01）；进行中正式尝试按需求基线后台收敛。

### 3.5 POST /employees/{id}/reset-password

生成新临时密码，响应结构与手工建档相同（一次性 `temporaryPassword`）。

## 4. 凭据批次下载

### GET /employees/credential-batches/{id}/download

批量建档生成的初始凭据包。

**约束（FR-AUTH-02）：**

- 仅发起导入的管理员可下载
- 生成后 24h 内有效
- **仅可成功下载一次**，首次下载后链接失效
- 凭据不进入备份；遗失只能重置密码

失败返回 `ORG_CREDENTIAL_BATCH_EXPIRED` 或 `ORG_CREDENTIAL_ALREADY_DOWNLOADED`。

---

## 5. 管理员与异常处置授权

### PATCH /employees/{id}/admin-grants

**请求：**

```json
{
  "isAdmin": true,
  "hasOutageDisposition": false,
  "reason": "接任题库管理员"
}
```

**规则（FR-AUTH-05）：**

- 必须保留至少一名有效且具备 `hasOutageDisposition` 的管理员
- 授权转移需审计
- 不能移除最后一位异常处置授权人

违反返回 `ORG_LAST_OUTAGE_ADMIN`（422）。

---

## 6. 错误码

| code | 说明 |
| --- | --- |
| `ORG_DEPARTMENT_NAME_DUPLICATE` | 同级部门重名 |
| `ORG_DEPARTMENT_HAS_CHILDREN` | 有下级不可停用 |
| `ORG_DEPARTMENT_HAS_EMPLOYEES` | 有员工不可停用 |
| `ORG_DEPARTMENT_CYCLE` | 移动成环 |
| `ORG_DUPLICATE_EMPLOYEE_NO` | 工号重复 |
| `ORG_DUPLICATE_PHONE` | 手机号重复 |
| `ORG_INVALID_DEPARTMENT_PATH` | 部门路径无效 |
| `ORG_CREDENTIAL_BATCH_EXPIRED` | 凭据包过期 |
| `ORG_CREDENTIAL_ALREADY_DOWNLOADED` | 凭据已下载 |
| `ORG_LAST_OUTAGE_ADMIN` | 不能移除最后授权人 |
