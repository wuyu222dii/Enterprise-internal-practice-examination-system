## 2. 客观题评分（FR-SCR-01）

评分在交卷服务端完成，不由客户端提交分数。

| 规则 | 说明 |
| --- | --- |
| 单选/判断 | 完全匹配得分，否则零分 |
| 多选 | 选项集合完全匹配得分，**不部分得分、不扣分** |
| 解答题 | 去空白后精确比对 |
| 未答 | 零分 |

评分失败时尝试保持 `submitting`，系统幂等重试直至唯一 `ExamResult`（FR-SCR-01）。

---

## 3. 官方成绩（FR-SCR-02）

| 规则 | 说明 |
| --- | --- |
| 口径 | 某员工某场考试全部**有效**已评分尝试的最高分 |
| 同分 | 取最早达到该分数的尝试 |
| 通过后 | 停止重考资格（员工端中性表达） |

`GET /admin/exams/{id}/scores/employees` 一人一行官方成绩。

## 4. 尝试作废（FR-SCR-03）

### POST /admin/exams/{id}/attempts/{attemptId}/void

**请求：**

```json
{
  "employeeVisibleReason": "因系统异常作废，请重新参加考试",
  "internalReason": "监控发现重复交卷风险，人工复核作废",
  "refundAttempt": true
}
```

**约束：**

- 交卷处理中（`submitting`）须等待完成后方可作废
- 作废不删除原答案与评分，仅退出官方成绩计算
- 可选返还尝试次数
- 触发官方成绩重算

**禁止：** 无接口可修改题项得分或通过状态。

## 5. 结果公开与脱敏（FR-SCR-04）

### GET /attempts/{id}/result（员工端）

**ResultVisibility 驱动响应字段：**

```json
{
  "attemptId": "att_xxx",
  "summaryVisible": true,
  "totalScore": 85.5,
  "maxScore": 100,
  "passingScoreVisible": false,
  "passConclusionVisible": false,
  "retakeNeutralMessage": "本场已无后续参加机会",
  "perItemReviewAllowed": false,
  "items": null
}
```

| 条件 | 行为 |
| --- | --- |
| 汇总未公开 | 不返回分数项 |
| 通过结论未公开 | 不返回 `passingScore`、不返回 `passed` |
| 逐题未开放 | `items=null`，不含答案/解析 |
| 整场结束且无合法机会后 | 可按策略开放逐题复盘 |

管理端 `GET /admin/exams/{id}/attempts/{attemptId}` 返回完整快照与评分依据。

## 7. 异步导出（FR-REP-03）

### POST /admin/exams/{id}/exports

**请求：**

```json
{
  "format": "xlsx",
  "includeSheets": ["officialSummary", "allAttempts"]
}
```

双工作表：官方汇总 + 全部尝试明细。

**响应：**

```json
{
  "jobId": "exp_xxx",
  "status": "pending"
}
```

### GET /admin/exports/{jobId}

```json
{
  "jobId": "exp_xxx",
  "status": "completed",
  "downloadUrl": "https://...",
  "expiresAt": "2026-08-31T12:00:00Z"
}
```

下载链接 **24 小时**有效；过期返回 `REP_EXPORT_EXPIRED`。

---

## 8. 错误码

| code | 说明 |
| --- | --- |
| `SCR_SUBMIT_IN_PROGRESS` | 评分进行中 |
| `SCR_ATTEMPT_NOT_VOIDABLE` | 状态不允许作废 |
| `REP_EXPORT_NOT_READY` | 导出未完成 |
| `REP_EXPORT_EXPIRED` | 下载链接过期 |
| `REP_RESULT_LOCKED` | 结果锁定保护中 |
