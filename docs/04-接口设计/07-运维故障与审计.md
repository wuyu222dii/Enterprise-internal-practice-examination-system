## 2. 平台故障事件（FR-OPS-01）

事件由**监控自动生成**，管理员不能创建或编辑事实字段。

### GET /admin/outage-events

分页列表；筛选 `status`、`affectedExamId`。

**OutageEvent 摘要：**

```json
{
  "id": "out_xxx",
  "status": "awaitingConfirmation",
  "candidateStartedAt": "2026-08-30T11:50:00Z",
  "openIntervalEnd": null,
  "affectedExamIds": ["exam_xxx"],
  "latestProposalVersion": 2,
  "createdAt": "2026-08-30T11:51:00Z"
}
```

**status 枚举：**

| 值 | 说明 |
| --- | --- |
| `open` | 影响区间开放，考试暂停 |
| `awaitingConfirmation` | 技术恢复后待管理员确认提案 |
| `underReview` | 驳回后系统复核中 |
| `confirmed` | 已确认并补时恢复 |
| `rejectedClosed` | 驳回且复核关闭（按基线收敛） |

### GET /admin/outage-events/{id}

含监控证据摘要、受影响考试、**不可编辑**的提案版本列表。

**OutageProposal：**

```json
{
  "version": 2,
  "closedIntervalStart": "2026-08-30T11:50:00Z",
  "closedIntervalEnd": "2026-08-30T12:15:00Z",
  "affectedScope": { "examIds": ["exam_xxx"] },
  "proposedCompensationMinutes": 25,
  "evidenceSummary": "核心考试服务写入失败率超阈",
  "editable": false
}
```

## 3. 授权确认与补时（FR-OPS-02）

### POST /admin/outage-events/{id}/proposals/{version}/confirm

**请求：**

```json
{
  "confirmationNote": "已核对监控证据，同意补时方案"
}
```

**效果：**

- 二次确认并审计
- 系统复核封闭区间与补偿分钟
- 统一顺延受影响考试的停止新开卷时间
- 恢复运行状态 `runStatus=normal`

旧版本提案确认返回 `409 OPS_PROPOSAL_STALE`。

### POST /admin/outage-events/{id}/proposals/{version}/reject

**请求：**

```json
{
  "rejectReason": "影响范围证据不足，请重新采集"
}
```

驳回后进入 `underReview`；**不**恢复考试、**不**取消应补时间；系统生成下一版本提案。

**禁止：** 管理员手工编辑提案字段、手工关闭开放区间、强制恢复。

## 4. 观察窗失守（SYS-05）

当尝试到期或整场结束 **20 秒观察窗**内故障处置失守时：

- 触发 `resultLocked` 保护标记
- 冻结官方结果、统计、导出与逐题披露
- 按需求基线强制取消并重建（管理端可见，员工端中性提示）

相关状态通过 `GET /admin/exams/{id}/monitor` 与考试详情返回，无独立员工写接口。

## 5. 审计日志（FR-OPS-03）

### GET /admin/audit-logs

**查询参数：** `actorId`、`actionType`、`targetType`、`targetId`、`from`、`to`、`page`、`pageSize`。

**AuditLog 条目：**

```json
{
  "id": "aud_xxx",
  "occurredAt": "2026-08-30T12:00:00Z",
  "actorEmployeeId": "emp_admin",
  "actorDisplayName": "管理员A",
  "actionType": "exam.publish",
  "targetType": "Exam",
  "targetId": "exam_xxx",
  "before": null,
  "after": { "lifecycle": "notStarted" },
  "reason": null,
  "requestId": "req_abc",
  "clientIp": "10.0.1.5"
}
```

**记录范围：** 发布、取消、作废、导入确认、权限变更、故障确认/驳回、安全拒绝、凭据下载等。

**禁止写入日志：** 明文密码、验证码、会话令牌、员工答案原文。

日志**追加写入**，保留期内不可物理删除；支持篡改检测（实现层细节，接口只读）。

---

## 6. 性能与保留（FR-OPS-04）

接口层需满足需求基线性能指标（500 并发写入、P95 等），在实现方案中验证；本 API 文档定义：

| 指标 | 端点示例 |
| --- | --- |
| 答案保存 P95 | `PUT /attempts/{id}/answers/{itemId}` |
| 开卷 P95 | `POST /exams/{id}/attempts` |
| 导出完成时限 | `GET /admin/exports/{jobId}` 异步 |

数据保留 **5 年**；无普通删除接口。

---

## 7. 错误码

| code | 说明 |
| --- | --- |
| `OPS_NOT_AUTHORIZED` | 无异常处置授权 |
| `OPS_PROPOSAL_STALE` | 提案版本已过期 |
| `OPS_EVENT_NOT_CONFIRMED` | 事件状态不允许操作 |
| `OPS_CONFIRMATION_REQUIRED` | 需二次确认 payload |
