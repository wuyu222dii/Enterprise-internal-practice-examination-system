## 2. POST /auth/login

工号密码登录，三端共用。

**请求：**

```json
{
  "employeeNo": "E10001",
  "password": "********",
  "clientType": "miniProgram"
}
```

`clientType` 枚举：`miniProgram` | `examWeb` | `adminWeb`。

**成功响应 `data`：**

```json
{
  "session": {
    "employeeId": "emp_xxx",
    "employeeNo": "E10001",
    "displayName": "张三",
    "roles": ["employee"],
    "isAdmin": false,
    "hasOutageDisposition": false,
    "mustChangePassword": true,
    "miniProgramBound": false
  }
}
```

**错误码：**

| code | HTTP | 说明 |
| --- | --- | --- |
| `AUTH_INVALID_CREDENTIALS` | 401 | 工号或密码错误 |
| `AUTH_ACCOUNT_LOCKED` | 403 | 连续失败锁定 |
| `AUTH_ACCOUNT_DISABLED` | 403 | 账号已停用 |

---

## 3. GET /auth/session

查询当前会话；用于路由守卫与权限摘要。

**成功响应 `data`：** 与 login 的 `session` 结构相同，附加 `serverNow` 于 `meta`。

未登录返回 `401 AUTH_SESSION_EXPIRED`。

---

## 4. POST /auth/change-password

首登改密、已登录改密、临时密码失效后改密。

**请求：**

```json
{
  "currentPassword": "********",
  "newPassword": "********"
}
```

首登场景 `currentPassword` 为临时密码。成功后 `mustChangePassword=false`，其他端旧会话按策略失效（同员工改密一律失效其他会话）。

**错误码：** `AUTH_PASSWORD_POLICY_VIOLATION`（422）、`AUTH_INVALID_CREDENTIALS`（401）。

---

## 5. POST /auth/sms/send

发送短信验证码。

**请求：**

```json
{
  "phone": "138****8000",
  "purpose": "bindMiniProgram"
}
```

`purpose` 枚举：`bindMiniProgram` | `resetPassword` | `unbindPhone`。

限流：同一手机号 60s 内不可重复发送；超限返回 `429 AUTH_SMS_RATE_LIMITED`。

---

## 6. POST /auth/sms/verify

校验验证码（绑定流程中间步骤）。

**请求：**

```json
{
  "phone": "13800138000",
  "code": "123456",
  "purpose": "bindMiniProgram"
}
```

**响应 `data`：**

```json
{
  "verificationToken": "vt_xxx",
  "expiresAt": "2026-08-30T12:10:00Z"
}
```

`verificationToken` 供 `POST /auth/mini-program/bind` 使用，单次有效。

---

## 7. POST /auth/mini-program/bind

小程序首次绑定；需有效 `verificationToken`。

**请求：**

```json
{
  "verificationToken": "vt_xxx",
  "miniProgramOpenId": "oXXXX"
}
```

绑定成功后 `miniProgramBound=true`；同一 openId 不可绑定其他员工。

---

## 8. POST /auth/password-reset

短信验证通过后的密码重置（未登录）。

**请求：**

```json
{
  "employeeNo": "E10001",
  "verificationToken": "vt_xxx",
  "newPassword": "********"
}
```

成功后该员工全部会话失效。

---

## 9. POST /auth/logout

注销当前会话。成功返回 `204 No Content`。

---

## 10. 对象级权限（FR-AUTH-06）

- 员工只能以本人身份访问员工端资源。
- 管理员接口需 `isAdmin=true`；故障确认需 `hasOutageDisposition=true`。
- 隐藏 UI 按钮不能替代服务端校验；所有下游接口重复校验会话与对象归属。
