## 1. 本地开发环境

```bash
docker compose up -d          # PostgreSQL:5433 Redis:6380 MinIO:19000/19001
cd backend && mvn spring-boot:run   # API :8088/api/v1
cd web-admin && npm run dev   # :5173（或 5180 用于 E2E）
cd web-exam && npm run dev    # :5174（或 5181 用于 E2E）
```

### E2E 联调

```bash
# 需 backend + docker 已启动
cd web-admin && E2E_WITH_BACKEND=1 npm run test:e2e
cd web-exam && E2E_WITH_BACKEND=1 npm run test:e2e
```

### 导出与对象存储

- 异步导出任务完成后，通过 `GET /admin/exports/{jobId}/download` 下载
- 存储后端：`exam.storage.backend=local|minio`（默认 `local`）
- 本地路径：`exam.storage.local-path`（默认 `./data/storage`）
- MinIO：`EXAM_MINIO_ENDPOINT` / `EXAM_MINIO_ACCESS_KEY` / `EXAM_MINIO_SECRET_KEY`（密钥走环境变量，不要写入 git）
- 凭据批次对象前缀 `credentials/`，**不得纳入备份目录**（见 `scripts/ops/backup.sh`）

### 生命周期清理（RetentionScheduler）

默认每小时执行一次（`exam.retention.interval-ms`）：

| 对象 | 规则 |
| --- | --- |
| 导题任务 | 30 天未确认 → 状态 `expired`，不可 confirm（IMP-09） |
| 导题源文件 | 180 天删除对象，任务元数据保留（RET-01） |
| 成绩导出 | `expiresAt` 到期删除文件 |
| 员工凭据 | 下载成功或 24h 到期删除文件（ACC-02） |

生产切换 MinIO：

```bash
export EXAM_STORAGE_BACKEND=minio
export EXAM_MINIO_ACCESS_KEY=...   # 不要提交到仓库
export EXAM_MINIO_SECRET_KEY=...
# 创建 bucket exam-files（应用启动时若不存在会尝试创建）
```

短信通道：`EXAM_SMS_PROVIDER=mock|aliyun|tencent`。生产真实供应商需另签合同；I12 仅提供适配器桩，OpenAPI 不变。

## 4. 生产部署

- 内网单机或主从 PostgreSQL（默认开发端口 **5433**）
- Redis 会话与幂等（开发端口 **6380**）
- MinIO 对象存储（开发 **19000/19001**），应用密钥与 MinIO 密钥分离
- 反向代理 TLS 终结
- CI：GitHub Actions 跑 `backend mvn test` 与两端 `npm run build` + Playwright 登录冒烟
- 灾备脚本见 `scripts/ops/backup.sh` / `restore.sh`
