## I11 容量与性能实测（2026-08-30）

数据集：`scripts/load-test/seed-capacity.sql`（5000 员工 / 50 部门 / 10000 题 / 50000 候选版本）。考试 `exm_c3199404299e42ed` 用于 CAP-01 / PERF-04；`exm_c9b2e621416e40a1` 用于开卷与到期抽样。本机 Docker PostgreSQL 15 + 单实例 API :8088。

| 验收 ID | 样本 | P50 | P95 | P99 / 最大 | 失败 | 结论 |
| --- | --- | --- | --- | --- | --- | --- |
| CAP-01 预检 | 50 规则 × 50000 版本 | — | — | 0.152s | 0 | 通过（<= 30s）；`exam_assignments` **恰为 2000** |
| CAP-01 发布展开 | 2000 人应考 | — | — | 0.900s | 0 | 通过（展开预览/发布 <= 10s） |
| PERF-04 导出 | 2000 人 × 10 次 = 20000 尝试 | 6.36s | 6.36s | 6.36s | 0 | 通过（<= 5min）；工作表行数 **2000 / 20000**；下载 1.26 MB |
| PERF-02 开卷 | 200 人 / 60s 到达（RATE=200） | 185ms | 255ms | 590ms | 0 / 200 | 开卷 P95 <= 3s；无重复在途尝试。**未跑满 500 开卷 + 500 交卷突发** |
| PERF-01 保存 | 50 VU × 1min，600 次保存 | 20ms | 1.10s | 1.31s | 0 / 600 | 失败率 0%；P95 略超 1s。**未跑满 500 人 30min** |
| PERF-03 到期 | 200 个同秒到期 | — | — | 调度一轮约 23s | 0 | 200 唯一提交 + 200 唯一结果，残留在途 0。**未跑满 500** |

复现：

```bash
docker exec -i exam_system-postgres-1 psql -U exam -d exam_system < scripts/load-test/seed-capacity.sql
EXAM_ID=$(scripts/load-test/setup-capacity-exam.sh | tail -1)
docker exec -i exam_system-postgres-1 psql -U exam -d exam_system -v exam_id="$EXAM_ID" \
  < scripts/load-test/seed-capacity-attempts.sql
EXAM_ID=$EXAM_ID k6 run scripts/load-test/perf04-export.js
```

全量 500 人 / 30 分钟指标需在独立压测机上按 `perf01-sustained.js` / `perf02-burst.js` / `perf03-expiry.js` 默认参数重跑，不得用本表抽样数字替代。操作说明见 [scripts/load-test/README.md](../../scripts/load-test/README.md)。

I12 已将保存 debounce 做到考试端 600ms，并保持 Hikari 连接池 60；全量 PERF-01 应在该基线上重测 P95。
