## 1. 文档目标与边界

本文档把需求基线转换为 Web 管理后台的页面、元素、交互、状态、异常和验收标准。它与 PRD 总览共同作为信息架构、交互设计、研发拆分和测试用例的业务输入。

本端负责组织与员工、题库与题目、Excel 导入、正式考试配置与发布、过程监控、异常处置、成绩导出和审计查询。不在后台提供员工练习、模拟考试或正式答题；任何管理员都不能直接修改员工答案、得分、通过结论、个人到期时间或已发布考试的冻结规则。

## 3. 角色、授权与全局交互

### 3.1 权限分层

| 身份/授权 | 能力 | 限制 |
| --- | --- | --- |
| 企业管理员 | 访问本企业后台，管理组织、员工、题库、考试、成绩与审计 | 不得修改已确认答案、评分结果或个人考试时间 |
| 异常处置授权 | 在企业管理员资格上叠加，可二次确认或驳回系统已创建的平台故障事件 | 不是第三种业务角色；不得手工创建事件，不得修改影响开始、结束、考试或尝试范围 |

异常处置授权只能授予有效企业管理员。只有已具有该授权的管理员能授予或撤销他人的该授权；撤销最后一名有效企业管理员或最后一名有效异常处置授权管理员时，操作必须被阻止。

### 3.2 全局状态和反馈

| 场景 | 统一要求 |
| --- | --- |
| 首次加载 | 页面主区域显示加载状态，不保留上一个对象的明细内容 |
| 空数据 | 说明当前筛选下无数据，只在具有创建权限且状态允许时提供主操作 |
| 查询失败 | 保留查询条件，显示可重试反馈，不将空结果伪装成失败 |
| 提交中 | 发起操作的控件进入单次处理状态，重复触发返回同一结果 |
| 无权限 | 页面不展示受保护内容；已打开页面在权限撤销后的下一次操作立即拒绝 |
| 对象已变更 | 拒绝基于旧数据的写入，要求重新加载最新状态 |
| 对象已冻结 | 表单改为只读，明确标识冻结时间与仅可修改的考试说明 |
| 高风险操作 | 发布、取消、作废、停用、资格/授权变更和故障确认/驳回均需二次确认 |
| 时间显示 | 同时显示企业时区名称；“停止新开卷时间”不得缩写为“考试结束时间” |

所有状态都必须同时使用文字与非单一颜色标识。一场考试在后台同时展示“考试生命周期”与“运行状态”；员工明细同时展示“参与状态”与“结果状态”，不将五个状态域合并为一列。“异常尝试”仅作为独立关注标记，不能成为任一状态域的新状态，也不进入人数守恒。“结果锁定/异常处理中”是严重一致性故障的独立保护标记和页面状态，同样不新增或改写五域枚举、不参与人数守恒；取消后仍按既有“已取消”状态收敛。

### 3.3 原因、脱敏与下载

- 整场取消和个人尝试作废均收集两类原因：“内部处置原因”与“员工可见说明”。两项均必填；内部原因仅在后台审计和有权管理页面显示，员工端只能看到可见说明。
- 手机号在列表中默认脱敏；仅在具有员工管理权限的详情操作中显示完整值。临时密码不进入列表、审计内容或后续查询。
- 错误结果、员工批量凭据、成绩文件和审计导出在下载前重新校验当前会话、权限和对象范围。
- 可下载文本必须以普通文本打开，不执行公式、外部链接或其他可执行内容。

## 5. 后台业务流程

| 流程 ID | 起点与结果 | 主要页面 | 关键阻断点 |
| --- | --- | --- | --- |
| `FL-EMP` | 创建部门 → 单个/批量建档 → 生成一次性凭据 → 首次改密 | `AD-02`、`AD-03`、`AD-04` | 部门路径不存在、工号/手机号冲突、凭据已下载 |
| `FL-QST` | 创建题库 → 建立分类/知识点 → 新建/修订题目 → 启停 | `AD-05`、`AD-06`、`AD-07` | 名称冲突、题型规则错误、历史版本不可编辑 |
| `FL-IMP` | 目标题库 → 下载模板/上传 → 校验预览 → 确认部分导入 → 结果 | `AD-08`、`AD-09` | 文件级失败、重复/冲突、未知层级未确认、预览过期 |
| `FL-PUB` | 创建草稿 → 五步配置 → 发布预检 → 二次确认 → 冻结发布 | `AD-10`、`AD-11`、`AD-12` | 人员为空、题量不足、候选重叠、容量超限、平台暂停 |
| `FL-OUT` | 监控创建已触发事件 → 技术恢复/健康检查 → 版本化提案待确认 → 确认并补时恢复，或驳回复核生成新版本 | `AD-04`、`AD-13`、`AD-16` | 开放区间未封闭、无授权、旧提案版本、不得手工关闭/强制恢复 |
| `FL-VOID` | 选择整场取消或个人尝试作废 → 填写内/外原因 → 二次确认 → 失效/重算 | `AD-13`、`AD-15` | 考试已取消、尝试交卷处理中、重复处理 |
| `FL-REP` | 选择考试 → 查看参与/结果统计 → 查看尝试 → 生成异步导出 → 24 小时内下载 | `AD-14`、`AD-15` | 无有效成绩、考试取消、任务失败、文件过期 |

## 6. 页面级需求

### AD-01 登录

#### 页面目标

完成管理员身份校验、首次临时密码更换和短信找回，只允许有效企业管理员进入后台。

#### 角色、入口与前置

- 入口：后台统一登录地址、会话失效跳转。
- 前置：账号已具有企业管理员资格且账号启用。
- 已登录但管理员资格已被撤销时，立即退出后台并返回登录页。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 账号登录 | 工号/账号、密码、登录 | 密码默认隐藏 | 失败文案不暴露账号是否存在 | `FR-AUTH-01` |
| 首次改密 | 新密码、确认密码 | 一次性临时密码登录后强制展示 | 完成前不开放业务导航 | `FR-AUTH-02` |
| 密码找回 | 账号、验证码、新密码 | 使用员工档案手机号 | 成功后原会话全部失效 | `FR-AUTH-03` |
| 会话状态 | 过期/撤权提示 | 不展示受保护数据 | 提供返回登录 | `FR-AUTH-01`、`FR-AUTH-06` |

#### 交互与校验

- 密码长度 8-64 个字符，大写、小写、数字、特殊字符至少满足三类，不得与工号或手机号相同。
- 同一账号 15 分钟内连续失败 5 次锁定 15 分钟。短信验证码有效 5 分钟，60 秒内不重发，每手机号每日最多 5 次，验证连续失败 5 次或成功使用后立即失效。
- 登录成功后按第 2.1 节规则跳转；跳转前重新确认管理员资格。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 正常 | 可提交登录 |
| 首次改密 | 只显示改密模块 |
| 账号锁定 | 提示稍后重试，不显示内部计数 |
| 账号停用/资格撤销 | 统一显示“无法进入管理后台” |
| 会话失效 | 清除当前页受保护内容并返回登录 |

#### 权限、脱敏、审计与观测

- 记录登录成功/失败、锁定、找回、改密和会话撤销，不记录密码、验证码或访问凭据原文。
- 观测登录失败率、锁定次数和找回成功率，不使用可识别凭据作为统计维度。

#### 来源规则与页面验收

- 来源：需求基线 4.2、4.5、17.4-17.5；`SYS-01`、`SYS-07`。
- `AD-01-AC-01`：一次性临时密码登录后只能先改密，完成后才进入后台（`ACC-02`）。
- `AD-01-AC-02`：连续失败、短信过期/复用/超频均给出无泄露的确定性反馈（`ACC-03`、`SEC-05`）。
- `AD-01-AC-03`：停用账号或撤销管理员资格后，旧会话下一次操作被拒绝且页面不残留受保护内容。

### AD-02 部门

#### 页面目标

管理无循环的部门树，以完整路径支撑员工主部门、考试人员选择和历史快照识别。

#### 角色、入口与前置

- 角色：企业管理员。
- 入口：“组织与员工 / 部门”。
- 前置：已通过 `AD-01` 身份校验。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 部门树 | 节点、层级、展开/收起 | 展示节点名和有效员工数 | 选中节点显示详情 | `FR-AUTH-04` |
| 部门详情 | 部门名、上级、完整路径、状态 | 完整路径只读 | 新增、改名、移动、启用/停用 | `FR-AUTH-04` |
| 影响提示 | 任意状态员工数、直接/间接下级数、已发布快照说明 | 改名、移动或停用前显示 | 明确停用阻断和历史快照不变 | `FR-AUTH-04`、`FR-EXM-03` |

#### 交互与校验

- 同一上级下部门名不得重复；不同上级下允许同名，所有选择器、列表、导入与导出均显示完整路径，例如“总部 / 技术中心 / 研发部”。
- 上级部门不能选择自身或任一下级节点。移动成功后同步更新当前完整路径，但不更改已发布人员快照。
- 存在任意有效或停用员工，或存在任意直接/间接下级部门时均不得停用；下级是否启用不改变阻断结果。第一阶段不物理删除部门。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 空树 | 提供创建根部门操作 |
| 循环移动 | 阻止保存并标记不合法上级 |
| 同路径冲突 | 阻止保存，展示冲突的完整路径 |
| 停用受阻 | 分别展示任意状态员工数和直接/间接下级部门数，不提供绕过停用 |
| 并发变更 | 拒绝旧页面保存，刷新为最新树 |

#### 权限、脱敏、审计与观测

- 只有企业管理员可写；记录新增、改名、移动、启停的前后摘要。
- 观测树加载失败、循环拦截和并发冲突，不将员工个人信息纳入该页面观测内容。

#### 来源规则与页面验收

- 来源：需求基线 4.3、10.4、17.5；`SYS-01`、`SYS-03`、`SYS-07`。
- `AD-02-AC-01`：移动部门时自身和下级不可选，合法移动后当前完整路径正确。
- `AD-02-AC-02`：两个同名叶子部门在选择、员工列表和导入错误中均可通过完整路径区分。
- `AD-02-AC-03`：部门改名或移动后，已发布考试中的部门快照不变（`PUB-04`）。
- `AD-02-AC-04`：部门存在有效或停用员工、直接或间接下级部门中的任一项时均不能停用；无员工且无下级时才可二次确认停用。

### AD-03 员工/员工导入

#### 页面目标

完成员工查询、单个建档、批量建档、主部门维护与账号启停，安全交付一次性临时凭据。

#### 角色、入口与前置

- 角色：企业管理员。
- 入口：“组织与员工 / 员工”。
- 前置：员工所属完整部门路径已存在且启用。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 筛选 | 姓名/工号、完整部门路径、账号状态 | 默认全部有效员工 | 查询、重置 | `FR-AUTH-04` |
| 员工列表 | 姓名、工号、完整部门路径、脱敏手机号、状态、管理员资格 | 一人一行 | 查看、编辑、启用/停用 | `FR-AUTH-04`、`FR-AUTH-05` |
| 单个建档 | 姓名、工号、主部门完整路径、手机号 | 账号默认启用 | 成功后仅一次显示临时密码 | `FR-AUTH-02`、`FR-AUTH-04` |
| 批量建档 | 模板下载、上传、预览数量、错误行、确认 | 部门列使用完整路径 | 可导入行部分建档 | `FR-AUTH-02`、`FR-AUTH-04` |
| 凭据交付 | 本次成功建档数、生成时间、剩余有效期、下载凭据 | 仅向发起管理员显示，生成后最多 24 小时有效 | 一次成功下载或到期后立即失效 | `FR-AUTH-02`、`AD-03-FN-01` |
| 历史影响 | 练习、考试、成绩保留说明 | 停用前显示 | 需二次确认 | `FR-AUTH-04`、`AD-03-FN-02` |

#### 交互与校验

- 姓名、工号、主部门完整路径和手机号必填；工号、手机号需与现有档案及本批次其他行共同校验唯一。
- 员工导入不创建部门。部门路径不存在、工号/手机号冲突的行跳过，其他合法行可确认建档；重复确认不重复创建账号。
- 单个创建成功后，临时密码只在结果层显示一次；关闭后不得再查看。批量创建的凭据文件仅发起管理员可见，自生成起最多 24 小时有效且只允许一次成功下载；首次下载完成或到期后页面显示“已失效，不可再次获取”，遗失或过期只能重置。
- 停用员工会立即撤销会话并禁止新业务请求；进行中尝试留待系统到期交卷，交卷处理继续收敛，已完成结果不变。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 无员工 | 提供单个建档和模板导入入口 |
| 部分可导入 | 分开显示可建档与冲突数，确认只创建合法行 |
| 批量凭据未下载且有效 | 显示剩余有效期并保持一次下载操作可用 |
| 批量凭据已下载 | 不再提供凭据原文；如遗失只能逐人重置 |
| 批量凭据已过期 | 禁用下载并提示只能重置，不能延长或重新生成原凭据包 |
| 员工已停用 | 保留历史记录，可重新启用 |

#### 权限、脱敏、审计与观测

#### 来源规则与页面验收

#### 交互与校验

- 仅接受系统当前版本 `.xlsx`；工作表、表头名与顺序固定。文件不得超过 1,000 个数据行或 10 MB，加密、损坏或无可解析数据按文件级失败。

- 管理员不能逐行或逐层级勾选。不同意任一待建层级时，必须取消任务、修改原文件并重新上传。
- 确认时按题库最新状态重新校验。预览依据已变时本次整体不写入，任务转为“需重新校验”。同一任务重复确认只返回首次结果。

- `AD-09-AC-01`：上传 1,000 行且接近 10 MB 的固定模板，60 秒内正确给出 972 行可导入、28 行不可导入和原行错误（`IMP-02`）。

### AD-11 五步配置向导

#### 页面目标

将正式考试草稿拆为可逐步校验的基础信息、组卷规则、应考人员、结果展示和复核五步，输出可执行发布预检的完整草稿。

#### 角色、入口与前置

- 角色：企业管理员。
- 入口：从 `AD-10` 创建或继续配置草稿。
- 前置：考试仍为草稿；已发布后本页只能查看冻结摘要，不能再保存。

#### 模块与元素

| 步骤 | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 1. 基础信息 | 考试名称、说明、开放开始、停止新开卷、单次时长、最大次数、及格分 | 时间显示企业时区 | 保存草稿、下一步 | `FR-EXM-01`、`FR-EXM-04` |
| 2. 组卷规则 | 题库、分类、知识点、题型、难度、抽题数、单题分值、候选数 | 单题分值默认 1；总题数/总分只读 | 新增、复制、删除草稿规则行 | `FR-EXM-02` |
| 3. 应考人员 | 全部员工、指定部门、指定员工、去重预览 | 部门显示完整路径并包含下级 | 预览姓名、工号、部门完整路径 | `FR-AUTH-04`、`FR-EXM-03` |
| 4. 结果展示 | 成绩公开时机、总分/通过/正确数/错误数开关、标准答案/解析开关 | 默认展示成绩和是否通过，答案/解析关 | 展示强制最早公开及结构化及格分隐藏说明 | `FR-SCR-04` |
| 5. 复核 | 四步汇总、题数/总分、应考数、未完成项 | 全部只读 | 返回指定步骤，或进入 `AD-12` | `FR-EXM-01`、`FR-EXM-02` |

#### 交互与校验

- 每一步提供“保存草稿”。进入下一步前完成当前步的表单校验；保存草稿允许暂时不完整，但不运行发布预检。
- 开放开始时间必须早于停止新开卷时间；单次时长为 1-480 的整数分钟，最大次数为 1-10。及格分在组卷总分确定后不得高于总分。
- 每条规则中题库必选；知识点仅在已选分类时可选。未选分类、知识点、题型或难度时，按需求基线的“全部”语义解释。抽题数为正整数，单题分值大于 0 且最多两位小数。
- 规则行为筛选维度交集，不将题型、知识点和难度解释为独立总配额。总分 = 各行抽题数 × 单题分值之和，不提供独立编辑。
- 人员范围取“全部员工、部门含下级、指定员工”的并集并去重。预览只纳入当前有效员工，完整路径用于区分同名部门。
- 第 4 步的汇总结果可配置为“本次提交后”或“整场考试结束后”。标准答案和解析即使开启，也必须等整场结束且员工无剩余合法机会后才可见。
- “是否通过”关闭或尚未到公开时机时，员工端不返回结构化及格分。第 4 步必须提示管理员不要在始终可见的考试说明中主动填写及格阈值，避免与已公开总分组合推导隐藏结论。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 未保存变更 | 切换步骤或离开页面前警示，可留在本页或放弃本次输入 |
| 规则暂时不完整 | 允许保存草稿，复核步将其列为阻断项 |
| 人员范围为空 | 不进入复核通过状态 |
| 及格分超总分 | 在第 2 步总分更新后立即标记第 1 步需修正 |
| 草稿已发布 | 立即转为只读，提供进入 `AD-13` |

#### 权限、脱敏、审计与观测

- 人员预览显示姓名、工号和完整部门路径，不显示手机号。规则列表只显示候选数，不在草稿中向非题库页面暴露标准答案。
- 记录草稿新建、每次保存的步骤和变更摘要；观测草稿保存失败、人员预览耗时和规则候选数计算失败。

#### 来源规则与页面验收

- 来源：需求基线 4.3、10.1-10.3、15.4、17.1-17.2；`FL-PUB`、`SYS-01`、`SYS-03`、`SYS-04`。
- `AD-11-AC-01`：五步顺序、字段依赖、越界值和不完整状态均给出定位到步骤的反馈。
- `AD-11-AC-02`：多部门与指定员工的并集预览正确去重，2,000 人范围在 10 秒内生成（`CAP-01`）。
- `AD-11-AC-03`：系统按规则行实时汇总题数和总分，及格分不得高于总分，总分无编辑入口。
- `AD-11-AC-04`：成绩、答案和解析的开关组合不能突破 `FR-SCR-04` 的公开下限；“是否通过”未公开时明确提示结构化及格分被隐藏，且考试说明不应主动写入该阈值（`VIS-01`、`VIS-02`）。

### AD-12 发布预检与冻结

#### 页面目标

在任何员工开卷前一次完成配置、人员、规则重叠、题量和容量预检，管理员复核通过后原子生成已发布冻结版本。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 预检总览 | 配置、时间、人员、规则、候选池、总分各项状态 | 默认自动运行 | 重新预检 | `FR-EXM-02` |
| 规则结果 | 行号、筛选条件、要求数、可用数、缺口、重叠行 | 定位到每条规则 | 失败可返回第 2 步修改 | `FR-EXM-02` |
| 人员快照预览 | 去重人数、部门完整路径分布、无效人数 | 只纳入有效员工 | 失败可返回第 3 步 | `FR-EXM-03` |

| 发布结果 | 发布时间、生命周期、冻结版本摘要 | 发布成功后只读 | 进入 `AD-13` | `FR-EXM-03`、`FR-EXM-04` |

#### 交互与校验

| 预检失败 | 按步骤和规则行展示所有已知失败，不只显示第一项 |
| 预检通过 | 展示冻结摘要与发布二次确认 |
| 依据已变 | 原通过标识失效，自动重新预检 |
| 平台暂停 | 禁止预检成果转发布，恢复后必须重新预检 |
| 发布处理中 | 重复操作查询同一发布结果，不生成第二个发布版本 |

#### 权限、脱敏、审计与观测

- 候选池在本页仅展示数量和冲突定位，不展示标准答案。人员快照不展示手机号。
- 记录预检结果摘要、发布人、冻结时间、规则/人员/候选版本数和重复请求；观测每项检查耗时和总耗时。

#### 来源规则与页面验收

- 来源：需求基线 10.2-10.4、17.1-17.3、18.4；`FL-PUB`、`SYS-03`、`SYS-05`、`SYS-07`。
- `AD-12-AC-01`：合法规则只生成一个已发布版本，题数/总分、人员和候选版本快照完整（`PUB-01`）。

| 故障事件 | 事件标识、事件状态、监控证据版本、候选开始、开放/封闭区间、影响考试/尝试、提案版本、补偿结果 | 普通管理员仅见事件状态；授权管理员可见完整只读提案 | 仅待确认版本可由授权用户确认或驳回 | `FR-OPS-01`、`FR-OPS-02` |
| 严重一致性故障 | 观察窗失守类型、误终结/误披露范围、官方结果锁定状态、强制处置说明 | 命中时置顶且不可忽略 | 仅可进入整场取消；取消后跳转 `AD-10` 人工新建考试 | `FR-OPS-01`、`FR-OPS-02`、`AD-13-FN-04` |
| 整场取消 | 内部处置原因、员工可见说明、影响摘要 | 两个原因默认空 | 二次确认后取消 | `FR-EXM-04`、`FR-SCR-04`、`AD-13-FN-03` |

#### 交互与校验

- 参与状态和结果状态必须分列和分指标展示。第二次尝试中的员工参与状态为考试中，结果状态可仍为未通过。“异常尝试”仅标记交卷处理超时、幂等评分持续失败或唯一试卷/唯一结果等一致性风险；它不改写原参与、尝试或结果状态，也不进入任一人数守恒式。关注列表按触发类型和处置进度筛选，恢复或处置后只清除当前关注标记并保留历史审计。
- 服务端到达当前停止新开卷时间后，无论是否存在在途尝试，页面都先显示“收尾中”和 20 秒整场结束观察窗。观察窗未完成、运行暂停中或存在待处置故障事件时，结束阻断原因必须可见，不得显示“已结束”、结算最终缺考或将依赖整场结束的内容标记为可公开。
- 观察窗完成且无在途尝试、运行状态正常、无待处置故障事件时才显示“已结束”。故障补时把停止新开卷时间顺延到未来时，生命周期原子恢复为“开放开卷”，原观察结果失效，并从新的停止时间重新计算观察窗。
- 考试说明修订保留发布原文、每次新文本、修改人和时间，不覆盖冻结版本。其他业务配置没有编辑入口。
- 取消在未开始、开放开卷、收尾中和已结束均可发起，两个原因均必填。二次确认必须明示不可恢复、在途尝试终止、已完成结果失去官方效力和答案/解析停止访问。
- 已取得交卷处理权的尝试继续收敛为已完成，但已取消考试下仅作审计事实。取消后不可恢复；需重考必须创建新考试。
- 故障事件只由监控创建为“已触发”，并携带证据版本、候选开始、开放影响区间和范围。页面不提供新建、编辑、删除、手工关闭或强制恢复；技术恢复与健康检查通过后，只能由系统封闭区间、生成不可编辑提案版本并转为“待确认”。
- 仅当前“待确认”提案版本可处置。授权管理员确认时必须填写复核意见并二次确认；系统基于该只读版本合并重叠区间，原子顺延停止新开卷时间和适用进行中尝试的到期时间，完成业务恢复并转为“已确认”。重复确认或提交旧版本返回既有结果，不叠加补时。
- 驳回必须填写内部复核说明并二次确认，事件转为“系统复核中”并保持暂停。系统结合新增或校正证据重新校验；只有健康检查正常且区间、范围、补偿全部通过，才生成新的不可编辑版本并回到“待确认”。管理员不能强制通过或强制恢复，实际暂停时间不得被驳回免除。
- 若任一 20 秒观察窗失守，已造成本应补时的尝试自动交卷或补时重开前逐题内容披露，页面必须立即显示严重一致性故障并锁定该场官方结果、统计、导出和继续披露。该状态不能确认保留、改分、回滚提交或原地修复；管理员只能填写员工可见说明和内部原因后取消整场考试，再从 `AD-10` 人工新建考试。
- 仅当全部受影响考试均已取消且技术服务已恢复、没有可继续补偿的正式考试时，系统才能把事件转为“已关闭”；管理员不能手工关闭。事件关闭不删除任何暂停、提案、驳回或证据历史。

#### 状态与异常

| 类型 | 状态 | 页面行为 |
| --- | --- | --- |
| 考试运行 | 正常运行 | 按生命周期展示过程，无故障操作 |
| 考试生命周期 | 整场结束观察中 | 显示 20 秒观察剩余和结束阻断；无在途也保持收尾，不结算最终缺考 |
| 考试运行 | 暂停中 | 高优先级显示受影响能力、开始时间和在途人数 |
| 故障事件 | 已触发 | 显示候选开始和开放区间；全部管理员只读，等待技术恢复及健康检查 |
| 故障事件 | 待确认 | 非授权管理员只见状态与进度；授权管理员查看当前完整只读提案并确认/驳回 |
| 故障事件 | 系统复核中 | 全部管理员只读，显示被驳回版本、驳回原因和复核进度，考试保持暂停 |
| 故障事件 | 已确认 | 展示确认的提案版本、原/新时间、受影响尝试数和补时合计；重复处理返回该结果 |
| 故障事件 | 已关闭 | 仅系统在全部受影响考试已取消且技术恢复后进入；保留完整历史 |
| 一致性处置 | 严重故障待取消 | 官方结果、统计、导出和员工逐题披露全部锁定；只开放双原因整场取消，不提供忽略或恢复 |
| 考试生命周期 | 已取消 | 过程与事件只读，无新考试写操作 |

#### 权限、脱敏、审计与观测

- 页面不提供视频监考、屏幕监控或远程操作考生设备。员工表不显示手机号或答案原文。未持有异常处置授权的管理员只能查看故障事件标识、暂停状态和处置进度，不能读取完整监控证据、区间、影响范围或补偿提案。任何管理员都不能创建、编辑、删除、手工关闭事件或强制恢复考试。
- 记录说明修订、整场取消的内/外原因、观察窗开始/完成/失守、误终结或误披露范围、官方效力锁定、生命周期回退、异常关注触发/清除，以及故障的证据版本、每个提案版本、状态转换、健康检查、确认/驳回、系统复核、补时、恢复/关闭和重复处理。观测状态刷新失败、故障告警延迟、待处置耗时和补偿结果。

#### 来源规则与页面验收

- 来源：需求基线 10.4-10.6、11、13.4、14、17.3、17.5；`FL-OUT`、`FL-VOID`、`SYS-03`、`SYS-04`、`SYS-05`、`SYS-07`。
- `AD-13-AC-01`：参与和结果两组状态可同时查看但不混合求和；异常关注可筛选但不成为状态或统计人数，与 `AD-14` 口径一致（`REP-01`）。
- `AD-13-AC-02`：取消任一已发布生命周期的考试后，尝试/结果留档但失效、不可恢复，两类原因分离展示（`CAN-01`）。
- `AD-13-AC-03`：监控触发的故障在 15 秒内进入暂停，事件区间/范围只读；无授权管理员不能处置（`OUT-01`、`OPS-01`）。
- `AD-13-AC-04`：事件严格按已触发 → 待确认 → 已确认，或待确认 → 系统复核中 → 新版本待确认转换；确认只补偿受影响时间且重复处理不叠加，驳回不遗漏任何实际暂停补偿（`OUT-01`）。
- `AD-13-AC-05`：发布后除说明文本外所有配置只读，时间仅因故障补偿变化（`PUB-05`）。
- `AD-13-AC-06`：到停止新开卷时间后无论有无在途均先完成 20 秒观察；观察/暂停/待处置故障期间不结束、不形成最终缺考、不解锁依赖结束的内容；补时到未来后恢复开放并重新计算观察窗（`TIM-02`、`VIS-02`、`OUT-01`）。
- `AD-13-AC-07`：管理员不能创建、编辑、删除、手工关闭事件或强制恢复；全部受影响考试取消且技术恢复后，系统进入已关闭并保留所有证据和提案版本。
- `AD-13-AC-08`：模拟告警晚于观察窗并造成误自动交卷或误逐题披露时，系统立即锁定官方结果、统计、导出和继续披露；页面不能忽略或保留，只能填写双原因取消并从 `AD-10` 人工新建考试（`OUT-01`）。

### AD-14 成绩统计与导出

#### 页面目标

按已发布人员快照展示参与与结果两类统计、一人一行官方成绩，并生成 24 小时内可下载的异步双工作表成绩文件。

#### 角色、入口与前置

- 角色：企业管理员。
- 入口：从 `AD-10` 成绩操作、`AD-13` 指标或员工行进入。
- 前置：考试已发布。考试未结束时展示过程口径，已结束时展示终态口径。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 考试摘要 | 名称、生命周期、运行状态、结束观察/阻断状态、官方结果锁定状态、应考数、及格分、总分 | 已取消、严重一致性故障或终态未形成时高优先级标识 | 返回监控 | `FR-EXM-05`、`FR-OPS-01`、`AD-14-FN-01` |
| 参与指标 | 应考、参加、未参加/缺考、考试中、已交卷、已参加无有效交卷 | 按生命周期显示 | 点击筛选主表 | `FR-REP-01` |
| 结果指标 | 有效成绩、无有效成绩、通过、未通过、通过率、平均分、最高/最低分 | 不与参与指标混合 | 点击筛选主表 | `FR-REP-01` |
| 员工成绩主表 | 姓名、工号、部门快照、参与状态、结果状态、官方得分、是否通过、有效/总尝试、官方用时、异常关注标记 | 一人一行；关注标记不改变状态 | 进入 `AD-15` 或 `AD-13` 关注列表 | `FR-REP-02`、`FR-SCR-02`、`AD-14-FN-02` |
| 导出任务 | 生成、状态、发起人、完成时间、失效时间、下载 | 状态为排队中/生成中/已完成/失败/已过期 | 生成后 24 小时内下载，过期后可重新生成 | `FR-REP-03` |

#### 交互与校验

- 开放/收尾期间满足：应考 = 未参加 + 考试中 + 已交卷 + 已参加无有效交卷。结束后满足：应考 = 缺考 + 已交卷 + 已参加无有效交卷；应考 = 参加 + 缺考；参加 = 通过 + 未通过 + 无有效成绩。异常关注标记不进入上述任一等式，同一尝试被标记前后人数不得变化。
- 到达停止新开卷时间后的 20 秒观察窗、运行暂停或待处置故障期间，只展示带“非最终”标识的当前统计；未参加不得提前转为缺考，不生成最终结论，也不得把依赖整场结束的内容视为已公开。补时恢复开放后，页面回到开放期口径并清除旧观察窗的终态倒计时。
- 严重一致性故障锁定官方效力后，不展示或导出官方成绩和终态统计；页面只保留带风险标识的历史事实并引导返回 `AD-13` 执行强制整场取消，不能以重新生成导出的方式绕过锁定。
- 通过率 = 通过人数 / 应考人数。平均分只计算存在有效官方成绩的员工；缺考和无有效成绩不按 0 分计入。
- 官方得分取最高有效分，同分取最早达到尝试。无有效成绩时，得分、是否通过和官方用时留空，不显示为 0 分或未通过。
- 一次导出固定产生一个文件，其中“官方成绩汇总”一人一行，“全部尝试明细”一次尝试一行。导出口径使用任务生成时的最新官方结果，与同时点页面一致。
- 下载前重新校验会话、管理员资格和考试对象范围。任务完成起 24 小时后文件不可下载，过期任务摘要仍保留。
- 已取消考试只显示取消前历史与“不计入官方统计”，不生成新的官方统计结论。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 尚无尝试 | 应考人员全部为未参加，成绩列留空 |
| 结束观察/暂停/待处置故障 | 当前统计标记非最终，缺考和整场终态不结算；异常关注仅作筛选标记 |
| 严重一致性故障锁定 | 官方成绩、终态统计和导出不可用；显示不可忽略原因并返回 `AD-13` 取消整场 |
| 多次尝试 | 主表显示官方尝试与有效/总次数，全部尝试在 `AD-15` 展开 |
| 尝试作废后重算 | 刷新该员工主表和全场指标，不保留过期官方分为当前值 |
| 考试已取消 | 所有指标附加“取消前历史”，导出不标识为官方结果 |
| 导出失败 | 显示失败时间和重新生成操作，不提供不完整文件 |
| 导出已过期 | 下载不可用，可重新生成 |

#### 权限、脱敏、审计与观测

- 主表不显示手机号。导出中的文本安全处理，不被表格工具当作公式执行。
- 记录导出发起、成功/失败、下载和过期；观测观察窗期间的终态拦截、异常关注口径、统计查询 P95、导出耗时、行数守恒和失败率。

#### 来源规则与页面验收

- 来源：需求基线 11.2-11.6、15.2-15.3、16.2-16.4、17.2、17.4；`FL-REP`、`SYS-01`、`SYS-04`、`SYS-06`、`SYS-07`。
- `AD-14-AC-01`：开放/收尾和已结束两类人数守恒式均成立，通过率分母为应考人数，平均分不纳入缺考/无有效成绩（`REP-01`）。
- `AD-14-AC-02`：多次尝试下官方分为最高有效分且同分取最早者，无有效成绩不伪造 0 分（`SCR-02`）。
- `AD-14-AC-03`：导出文件固定包含官方汇总与全部尝试两个工作表，行数与页面口径一致（`REP-02`）。
- `AD-14-AC-04`：2,000 人、每人 10 次尝试的文件 5 分钟内生成，完成后 24 小时可下载，过期后拒绝（`PERF-04`、`RET-01`）。
- `AD-14-AC-05`：整场观察、暂停或待处置故障期间页面与导出均不形成最终缺考或终态口径；异常关注标记不改变任何守恒人数，补时恢复开放后切回开放期统计（`TIM-02`、`OUT-01`、`REP-01`）。
- `AD-14-AC-06`：严重一致性故障触发后，官方成绩、终态统计和导出均被锁定，重新查询或重复创建导出不能绕过，只能返回 `AD-13` 完成整场取消（`OUT-01`）。

### AD-15 尝试详情与作废

#### 页面目标

还原某名员工在某场考试的全部尝试、固定试卷、已确认答案、时间和评分事实，在不改写原数据的情况下作废合法状态的个人尝试。

#### 角色、入口与前置

- 角色：企业管理员。
- 入口：从 `AD-13` 员工过程表或 `AD-14` 成绩主表进入。
- 前置：员工属于该考试发布人员快照，且至少创建过一次尝试。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 员工/考试快照 | 姓名、工号、部门快照、考试名称、及格分、官方结果 | 发布与当前结果分区 | 返回成绩主表 | `FR-EXM-03`、`FR-SCR-02` |
| 尝试列表 | 序号、状态、有效性、官方尝试、异常关注标记、开始/到期/提交、原因、补时、用时、得分 | 时间先后排列；关注标记与状态分列 | 选中查看固定试卷 | `FR-ATT-02`、`FR-REP-02`、`AD-15-FN-01` |
| 固定试卷 | 题序、题目版本、题干/选项、员工答案、标准答案、分值/得分 | 全部只读 | 按已答/未答/正确/错误筛选 | `FR-ATT-02`、`FR-SCR-01` |
| 时间线 | 开卷、答案确认摘要、到期、交卷、评分、故障补偿、异常关注、作废 | 不显示每次自动保存原文 | 查看事件摘要 | `AD-15-FN-01` |
| 尝试作废 | 内部处置原因、员工可见说明、次数/官方成绩影响预览 | 仅进行中或已完成尝试可用 | 二次确认后作废 | `FR-SCR-03` |

#### 交互与校验

- 个人试卷、题目顺序、选项顺序、题目版本、员工答案、标准答案、分值、得分、时间与终结原因全部只读。页面不提供改题、改答案、改分、改通过结论或个人加时。
- 异常关注标记及其触发、恢复或确认处置记录只读展示，不改变尝试原状态、有效性或得分；清除关注标记后仍可从时间线追溯历史。
- 作废可作用于进行中或已完成尝试；交卷处理中必须等待收敛为已完成。已作废、已终止或整场已取消时不可再次作废。
- 内部处置原因和员工可见说明均必填。二次确认展示：原试卷/答案/得分保留、该尝试退出已用次数和官方成绩、返还一次次数、立即重算。
- 作废不延长开放时间或个人到期时间。已到停止新开卷时间时，即使返还次数也不能再创建尝试。
- 作废后从剩余未作废已完成尝试中重新选择最高分，同分取最早者。当前结果可从通过变为未通过、待定或无有效成绩。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 进行中 | 试卷与已确认答案只读，可作废 |
| 交卷处理中 | 作废不可用，页面刷新处理状态 |
| 已完成 | 显示唯一评分结果，可作废 |
| 已作废 | 显示作废人、时间和内/外原因，不再提供作废 |
| 已终止/整场取消 | 全部只读，明确无官方效力 |
| 作废处理中 | 重复请求返回同一结果，不重复返还次数 |

#### 权限、脱敏、审计与观测

- 员工答案和标准答案只对当前企业的有权管理员显示，不进入通用列表或审计摘要。每次打开尝试均校验考试对象归属。
- 记录作废内/外原因、操作人、时间、原/新官方结果摘要和返还次数；观测评分重现失败、作废重算耗时和重复处理。

#### 来源规则与页面验收

- 来源：需求基线 5.4、11.5-11.6、12.3、13.5、15.1-15.3、16.4、17.3-17.5；`FL-VOID`、`SYS-01`、`SYS-04`、`SYS-06`、`SYS-07`。
- `AD-15-AC-01`：固定试卷、答案、分值和评分只读，使用冻结版本可重现与原结果相同的严格评分（`SCR-01`）。
- `AD-15-AC-02`：进行中/已完成可作废，交卷处理中被阻止；作废后原数据不改，仅返还一次并立即重算（`SCR-03`）。
- `AD-15-AC-03`：作废官方尝试后，`AD-14` 官方分、通过结论和统计同步使用剩余有效尝试重算结果。
- `AD-15-AC-04`：试图修改答案、得分、用时、通过状态或个人到期时间均被拒绝并留痕（`SEC-04`）。
- `AD-15-AC-05`：异常关注与尝试状态分列；触发或清除标记不改写尝试状态、答案、评分及历史审计。

### AD-16 审计

#### 页面目标

以只读、可验证的方式查询关键管理、安全、下载和系统处理事件，支持业务追溯但不泄露凭据或员工答案原文。

#### 角色、入口与前置

- 角色：企业管理员。
- 入口：“审计 / 审计日志”，或从具体对象的“查看审计”跳转并预置对象筛选。
- 前置：已登录且仍具有企业管理员资格。

#### 模块与元素

| Module | 元素 | 显示/默认 | 操作与反馈 | 功能 ID |
| --- | --- | --- | --- | --- |
| 筛选 | 时间、操作人、角色、操作类型、对象类型/标识、执行结果、请求追踪标识 | 默认最近记录 | 查询、重置 | `FR-OPS-03` |
| 审计列表 | 时间、操作人、角色、操作、对象、结果、来源摘要、追踪标识 | 新记录在前 | 打开详情 | `FR-OPS-03` |
| 审计详情 | 前后值摘要、内部原因、员工可见说明、执行结果、完整追踪标识 | 只读 | 复制追踪标识 | `FR-OPS-03` |
| 故障事件链 | 已触发/待确认/系统复核中/已确认/已关闭、证据版本、提案版本、区间、范围、补偿和状态转换 | 普通管理员脱敏；授权管理员可查看完整事实 | 按事件/版本串联查看，不提供写操作 | `FR-OPS-02`、`FR-OPS-03`、`AD-16-FN-01` |
| 完整性状态 | 记录验证结果、最后验证时间 | 正常时显示可验证 | 失败时只读告警，不允许后台修复 | `FR-OPS-03`、`FR-OPS-04` |
| 导出当前结果 | 筛选摘要、生成、下载 | 仅导出有权范围 | 下载前重新校验权限并记录新审计 | `FR-AUTH-06`、`FR-OPS-03` |

#### 交互与校验

- 审计日志在应用内永久只读，不提供修改或删除。日志至少包含操作人、角色、时间、来源、操作类型、目标对象、执行结果、前后摘要、原因和追踪标识。
- 覆盖登录/找回/绑定，部门/员工/授权，导入，题目版本/启停，考试创建/发布/说明修订/取消，开卷/交卷/评分/作废，故障/补时，下载，授权拒绝，清理和恢复等类型。
- 故障事件链必须按相同状态展示：已触发 → 待确认 → 已确认，或待确认 → 系统复核中 → 新提案版本待确认；全部受影响考试取消且技术恢复时可由系统转为已关闭。每次状态转换引用对应证据版本、提案版本、健康检查、区间、影响范围、复核意见、补偿和业务恢复结果。
- 审计页没有创建、编辑、删除、手工关闭故障事件或强制恢复入口；即使操作者持有异常处置授权，也只能在 `AD-13` 对当前待确认提案执行确认或驳回。
- 密码、短信验证码、访问凭据、一次性临时密码和员工答案原文不得出现在列表、详情或导出中。
- 导出使用当前筛选条件；导出操作本身生成新的审计记录。导出文本不执行公式或外部链接。
- 审计与安全日志至少保留 5 年。到期清理按受控保留策略执行，清理行为本身也必须留痕。

#### 状态与异常

| 状态 | 页面行为 |
| --- | --- |
| 无匹配记录 | 保留筛选条件，不显示修改/删除入口 |
| 完整性可验证 | 显示最后验证成功时间 |
| 完整性告警 | 高优先级显示告警和追踪标识，后台不能修改原日志 |
| 故障链不完整 | 标记缺失的证据/提案版本或非法状态跳转并持续告警，不补写或改写原审计 |
| 对象已过保留期 | 仅在保留策略允许且已清理时显示摘要，不伪造对象明细 |
| 导出权限已撤销 | 立即拒绝下载并留下授权拒绝记录 |

#### 权限、脱敏、审计与观测

- 查看与导出审计也需记录操作人、范围、时间和结果。所有脱敏规则同样适用于导出；未持异常处置授权者不能通过审计导出绕过故障提案脱敏。
- 观测日志完整性验证、故障证据/提案版本连续性、非法状态跳转、查询失败、导出失败、越权查看和到期清理。

#### 来源规则与页面验收

- 来源：需求基线 14.1-14.3、17.4-17.7、18.6；`SYS-01`、`SYS-05`、`SYS-07`。
- `AD-16-AC-01`：从需求基线 17.5 每类事件抽样，操作人、时间、对象、前后摘要、原因、结果和追踪标识完整（`AUD-01`）。
- `AD-16-AC-02`：管理员不能修改或删除日志，完整性检查可发现篡改，且日志无凭据或答案原文。
- `AD-16-AC-03`：模拟业务时间验证 5 年保留、引用保护和受控清理，清理行为自身有日志（`RET-01`）。
- `AD-16-AC-04`：审计导出在权限撤销后不可下载，失败请求不泄露原数据（`SEC-01`）。
- `AD-16-AC-05`：故障事件每次证据、提案版本和五态转换可串联重放；不存在管理员创建、编辑、手工关闭或强制恢复记录，非法跳转被完整性观测发现（`OUT-01`、`AUD-01`）。

## 9. 文档验收清单

- `AD-01` 至 `AD-16` 各定义一次，一级导航仅包含组织与员工、题库、考试和审计。
- 每页均包含页面目标、角色/入口/前置、模块元素、交互校验、状态异常、权限脱敏、审计观测、来源与页面验收。
- 答案、得分、时间、已发布快照和审计日志的只读语义在所有页面一致。
- 导题、发布、取消、故障补时、尝试作废和导出的重复请求不产生重复业务结果。
- 所有故障事件只由监控创建；证据和提案按版本留痕，授权管理员只能确认或驳回当前待确认版本。管理员不能编辑、手工关闭或强制恢复；驳回不能抹消已实际暂停时间的最终补偿。
- 停止新开卷后无论有无在途尝试均先完成 20 秒整场结束观察；观察、暂停或待处置故障期间不结算最终缺考或形成结束口径，补时到未来后恢复开放并重新观察。
- 异常尝试始终是可筛选的独立关注标记，不改变参与、尝试或结果状态，也不进入人数守恒。
- 成绩导出只有双工作表口径，文件自完成起 24 小时有效，界面、导出与尝试详情口径一致。
