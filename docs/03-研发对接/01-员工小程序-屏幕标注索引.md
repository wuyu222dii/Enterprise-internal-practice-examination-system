## Part A — 全局约束

来源：Figma「研发标注 · 员工小程序」。

### A.1 职责边界

- 本端仅：**练习 / 模拟 / 任务查看**。
- **NEVER 正式作答**。不得出现「开始正式考试」主按钮。
- 正式作答仅在「02 正式考试端」（Web）。考试 Tab 只定位任务，不替代登录。

### A.2 设计令牌

详见 [视觉与组件规范 §1](./01-员工小程序-视觉与组件规范.md#1-设计令牌)。

### A.3 账号规则

- 登录账号 = **工号**，不是手机号。
- 手机号仅用于短信找回 / 绑定 / 解绑。
- 失败提示**不得暴露账号是否存在**。
- 错误文案统一为「**工号或密码错误**」，不区分账号不存在与密码错误。

### A.4 会话规则

- 全模式（练习 / 模拟 / 正式任务查看）最多 **1 个进行中会话**。
- 切换模式须继续或结束当前会话；冲突时弹窗处理（M-05b）。
