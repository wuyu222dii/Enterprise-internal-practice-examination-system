## Part A — 全局约束

来源：Figma「研发标注 · 管理后台」。

### A.1 职责边界

- 本端：人员/题库/考试组织/监考/成绩与审计。
- **管理不得改分、不得改答案。**
- 无有效成绩不得伪造成 0/未通过。
- **无视频监考。**

### A.2 账号规则

- 登录账号 = **工号**，不是手机号。
- 手机号仅用于短信找回 / 绑定 / 解绑。
- 管理员**不可手改故障区间**，仅确认/驳回。
