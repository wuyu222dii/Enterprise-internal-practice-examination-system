## 2. 页面布局

### 2.1 通用结构

正式考试端**不使用** `AdminSidebar`，采用 Topbar + 主内容区布局：

```
┌──────────────────────────────────────────────┐
│ Topbar（54px）· 品牌 / 用户信息              │
├──────────────────────────────────────────────┤
│ Body · 列表 / 表单 / 工作台                   │
└──────────────────────────────────────────────┘
```

### 2.2 登录页（E-01）

- 居中 `LoginCard`：440 × 553，距顶约 173px
- 品牌区：Mark +「正式考试端」
- 表单区：Input × 2 + Primary / Secondary Button

### 2.3 作答工作台（E-05）

```
┌──────────────────────────────────────────────┐
│ StickyTop · 考试名 / 已答进度 / 倒计时 / 保存 / 交卷 │
├──────────┬───────────────────────────────────┤
│ 答题卡    │ 题目区 + OptionRow                 │
│ 280px    │                                   │
└──────────┴───────────────────────────────────┘
```

## 3. 复用组件

组件变体定义见 [员工小程序 — 视觉与组件规范 §2](./01-员工小程序-视觉与组件规范.md#2-组件库概览)。本端使用 subset 如下：

| 组件 | 本端约束 |
| --- | --- |
| Button | Primary 用于登录、开卷、交卷；Secondary 用于找回密码、取消 |
| Input | 工号、密码、考试码、短信验证码 |
| Tag | 任务状态、五域状态标签 |
| StatusSave | 作答页顶部；Saving / Saved / Failed 三态 |
| OptionRow | **仅 Default / Selected**；作答中不显示正误 |

## 4. 考试端特有规范

### 4.1 倒计时

| 场景 | 规范 |
| --- | --- |
| 常规 | StickyTop 右侧显示 `HH:MM:SS`，以服务端 `expireAt` 为准 |
| 最后 1 分钟 | 倒计时变红（E-05e，`#DC2626`） |
| 平台暂停 | 计时停止，页面只读（E-06） |
| 到期观察窗 | 约 20s 不可编辑，超时已自动交卷（E-12） |

### 4.2 答题卡

- 左侧固定宽 280px
- 图例：**当前**（深蓝描边）、**已答**（蓝底）、**未答**（灰底）、**标记**（琥珀底）
- 须同时使用**文字 + 颜色**表达状态（标注 E-05）

### 4.3 保存与交卷

| 状态 | 表现 |
| --- | --- |
| 保存中 | StatusSave = Saving |
| 已保存 | 仅服务端确认后显示 Saved |
| 保存失败 | Failed + 可重试（E-05d）；不清空已选答案 |
| 未确认保存 | 阻止交卷（E-07b） |
| 交卷处理中 | 试卷锁定，只展示处理状态（E-08） |

### 4.4 暂停与故障

- 平台故障暂停：停写入、停计时；个人断网无补时（E-06）
- 暂停解除后按服务端 `expireAt` 恢复，不可本地补时

### 4.5 结果展示

- 未公布不得提前泄露分数、对错或解析（E-09）
- 无有效成绩不得显示为 0/未通过
- 已公布 + 复盘见 E-09b；场次取消见 E-09c
