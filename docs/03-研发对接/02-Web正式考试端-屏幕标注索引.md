## Part A — 全局约束

来源：Figma「研发标注 · 正式考试端」。

### A.1 职责边界

- 本端**仅正式考试作答**。
- 不承担练习/模拟。
- 登录账号 = 工号。
- 试卷在尝试内固定；倒计时以服务端 `expireAt` 为准。

### A.2 账号规则

- 登录账号 = **工号**，不是手机号。
- 手机号仅用于短信找回 / 绑定 / 解绑。
- **考试码仅定位场次，不替代登录。**

### A.3 计时 / 保存 / 交卷

- 「已保存」仅能在服务端确认后出现。
- 保存失败须可重试，且阻止交卷直至确认保存（E-07b）。
- 平台故障暂停：停写入、停计时；个人断网无补时。
- 到期观察窗约 20s 不可编辑，超时已自动交卷。
