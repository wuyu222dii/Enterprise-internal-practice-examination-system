## 2. 组件库概览

Figma 区块 `00 组件（非交付）` 为**参考组件库**，不作为独立交付物。研发需按变体规格在小程序中实现等价组件。

### 2.1 Button

| 变体 | Figma 符号 | 使用场景 |
| --- | --- | --- |
| Primary | `Type=Primary` | 页面唯一主操作（登录、开始练习、提交配置） |
| Secondary | `Type=Secondary` | 次要操作（找回密码、取消） |
| Ghost | `Type=Ghost` | 低优先级文字按钮 |
| Danger | `Type=Danger` | 不可逆操作（放弃模拟、解绑） |
| Disabled | `Type=Disabled` | 不可用态，禁止点击 |

**约束：** 单页只保留一个明确 Primary 主操作。

### 2.2 Tag

| 变体 | Figma 符号 | 使用场景 |
| --- | --- | --- |
| Success | `Status=Success` | 已通过、回答正确 |
| Warning | `Status=Warning` | 待处理、观察中 |
| Danger | `Status=Danger` | 失败、已取消 |
| Info | `Status=Info` | 中性信息（题型标签等） |
| Saved | `Status=Saved` | 已保存 |
| Unanswered | `Status=Unanswered` | 答题卡未答 |
| Answered | `Status=Answered` | 答题卡已答 |

### 2.3 Input

| 属性 | 说明 |
| --- | --- |
| 尺寸 | 宽 327px（375 画布下左右各 24px 边距），高 68px（含标签） |
| 用途 | 工号、密码、手机号、验证码输入 |
| 校验 | 工号字段校验工号格式；不得将手机号作为登录账号 |

### 2.4 StatusSave

保存状态指示器，用于模拟/正式作答页顶部。

| 变体 | Figma 符号 | 显示文案 | 触发条件 |
| --- | --- | --- | --- |
| Saving | `State=Saving` | 保存中 | 答案提交后、服务端确认前 |
| Saved | `State=Saved` | 已保存 | 服务端确认保存成功 |
| Failed | `State=Failed` | 保存失败 | 保存请求失败，可重试 |

**约束：** 「已保存」态仅能在服务端确认后出现，不得本地乐观展示。

### 2.5 OptionRow

选项行，用于单选/多选/判断题。

| 变体 | Figma 符号 | 可用场景 |
| --- | --- | --- |
| Default | `State=Default` | 全部场景 |
| Selected | `State=Selected` | 全部场景（选中未提交 / 模拟/正式已选） |
| Correct | `State=Correct` | **仅练习模式**（提交后立即反馈） |
| Wrong | `State=Wrong` | **仅练习模式**（提交后立即反馈） |

**约束：**

- **练习（M-07）：** 提交后可展示 Correct / Wrong + 解析 banner。
- **模拟（M-09）：** 作答中**不显示正误**，仅 Default / Selected。
- **正式考试端：** 不在小程序实现；Web 端待 Figma 设计稿。

### 2.6 TabBar

底部四 Tab 导航，顺序固定不可调整。

| 变体 | Figma 符号 | Tab 名称 | 默认页面 |
| --- | --- | --- | --- |
| Practice | `Active=Practice` | 练习 | M-05 练习首页 |
| Mock | `Active=Mock` | 模拟 | M-08c 模拟Tab首页 |
| Exam | `Active=Exam` | 考试 | M-11 正式考试任务列表 |
| Mine | `Active=Mine` | 我的 | M-我的 |

**约束：** 沉浸式答题页（M-07、M-09）不展示 TabBar。

### 2.7 StatusBar

## 3. 页面布局规范

### 3.1 通用结构

```
┌─────────────────────────┐
│ StatusBar (44px)        │
├─────────────────────────┤
│ Header (可变高度)        │
├─────────────────────────┤
│ Body (scroll)           │
│   卡片 / 列表 / 表单     │
├─────────────────────────┤
│ StickyNav / TabBar      │  ← 沉浸式页用 StickyNav，一级页用 TabBar
└─────────────────────────┘
```

### 3.2 边距

| 区域 | 规范 |
| --- | --- |
| 页面左右边距 | 16px（Body 内卡片）或 24px（Header / Form） |
| 卡片内边距 | 12 ~ 16px |
| 卡片间距 | 12 ~ 16px |

### 3.3 骨架屏（M-练习加载中）

- 使用圆角矩形占位块（`sk-title`、`sk-sub`、`sk-session`、`sk-bank`、`sk-row`）。
- 加载中**不展示**真实对错或成绩数据。
- 失败时提供重试入口。

## 4. 交互与状态表达

| 场景 | 规范 |
| --- | --- |
| 练习即时反馈 | 提交后立即显示「回答正确/回答错误」banner + 解析区块 |
| 模拟作答 | 顶部倒计时 + StatusSave；OptionRow 不展示正误 |
| 答题卡 | 网格 28×28 题号格；已答/未答用 Tag 色区分 |
| 正式任务 | 列表卡片点击进入详情；**无「开始作答」主按钮** |
| 空态 | 独立屏幕帧（如 M-11b、M-错题本空态、M-无开放题库） |

## 5. 可访问性与多端适配

| 项目 | 要求 |
| --- | --- |
| 最窄宽度 | 320px 下无文本溢出或控件遮挡（PRD 要求） |
| 字号 | 不随视口宽度缩放 |
| 状态表达 | 不只依赖颜色；图标/文字并用 |
| 焦点 | Web 端键盘焦点可见（小程序按平台规范） |
