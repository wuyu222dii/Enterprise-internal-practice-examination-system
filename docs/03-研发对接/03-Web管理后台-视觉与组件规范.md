## 2. 页面布局

### 2.1 标准双栏结构

```
┌──────────┬───────────────────────────────────┐
│ Admin    │ Main                               │
│ Sidebar  │  Head（标题 + 操作）                │
│ 232px    │  Body（表格 / 表单 / 向导）          │
└──────────┴───────────────────────────────────┘
```

- `AdminSidebar`：固定宽 232px，高度 900px（Figma 组件库）
- `Main`：剩余宽度（1440 − 232 = 1208px），左右内边距 24px

### 2.2 登录页（A-01）

- 导航外独立页，不使用 AdminSidebar
- 居中登录卡片，与考试端登录风格一致

### 2.3 抽屉（A-26 尝试明细抽屉）

- 从右侧滑出，覆盖主内容区
- 用于尝试明细只读查看，不新增独立路由页

## 3. 组件规范

### 3.1 AdminSidebar

| 属性 | 说明 |
| --- | --- |
| 宽度 | 232px |
| 一级导航 | 组织与员工、题库、考试、审计（PRD §2.1） |
| 高亮 | 当前模块 NavItem = Active |

### 3.2 NavItem

| 变体 | 用途 |
| --- | --- |
| Default | 未选中导航项 |
| Active | 当前页面对应导航项 |

详见 [员工小程序 — 视觉与组件规范 §2.8](./01-员工小程序-视觉与组件规范.md#28-web-端预留组件小程序不交付)（组件库来源）。

### 3.3 共享组件

| 组件 | 管理端用途 |
| --- | --- |
| Button | Primary 主操作；Danger 作废/取消整场 |
| Input | 搜索、表单字段 |
| Tag | 考试生命周期、运行状态、参与/结果状态 |

### 3.4 管理端特有模式

| 模式 | 说明 | 示例屏幕 |
| --- | --- | --- |
| 密集表格 | 可扫描、状态域分列，不用单列混合表达 | A-03、A-19 |
| 步骤向导 | 创建考试多步配置 | A-13 |
| 只读冻结 | 已发布考试关键字段不可编辑 | A-17 |
| 预检查列表 | 发布前逐项校验，任一项失败禁用发布 | A-16 |
| 故障时间线 | 系统生成区间，管理员仅确认/驳回 | A-23 |
| 版本轨 | 题目版本历史只读时间线 | A-25 |

## 4. 交互约束

| 场景 | 规范 |
| --- | --- |
| 高风险操作 | 发布、取消、作废、停用、授权变更、故障确认/驳回均需二次确认 |
| 改分改答案 | **禁止**；无有效成绩不得伪造成 0/未通过 |
| 故障区间 | 管理员不可手改起止；仅确认/驳回系统检测提案 |
| 视频监考 | **不提供**视频流（A-18） |
| 状态分列 | 参与维与结果维不得混合求和；五域状态独立展示 |
| 导题 | 预览后确认才写入；错误行不得入库（A-10、A-27） |
| 组卷规则 | 发布后不可改规则影响已开考尝试；变更产生新版本（A-14） |
