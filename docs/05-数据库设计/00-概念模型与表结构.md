## 1. 设计原则

1. 主键使用 `VARCHAR(32)` opaque ID（应用层 `IdGenerator` 生成）。
2. 时间字段一律 `TIMESTAMPTZ`，存储 UTC。
3. 题目版本、发布版本、试卷快照**不可变**；修改通过新版本或新记录。
4. 幂等与不变量通过**唯一索引 + 事务**保障（见 §4）。
5. MVP 单企业单租户，无 `tenant_id`。

## 3. 关键字段说明

### 3.1 employees

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| employee_no | VARCHAR(50) | UNIQUE，登录账号 |
| must_change_password | BOOLEAN | 首登/重置后强制改密 |
| has_outage_disposition | BOOLEAN | 故障处置授权 |
| failed_login_count / locked_until | | 15 分钟 5 次锁定 |

### 3.2 exam_attempts

| 字段 | 说明 |
| --- | --- |
| attempt_status | inProgress / submitting / completed / voided / terminated |
| expires_at | 服务端计时边界 |
| voided | 作废标记，不删原数据 |

**部分唯一索引** `idx_exam_attempt_in_progress`：同一 `(exam_id, employee_id)` 在 inProgress/submitting 时最多一行。

### 3.3 exam_answers

| 字段 | 说明 |
| --- | --- |
| answer_version | 单调递增，乐观并发 |
| save_status | pending / saved / failed |

## 4. 不变量与索引

| 不变量 | 实现 |
| --- | --- |
| 单在途尝试 | `idx_exam_attempt_in_progress` + 开卷事务 |
| 答案版本不覆盖 | `answer_version` 比较 + 409 |
| 幂等开卷/交卷 | `idempotency_records(idempotency_key, scope)` |
| 题目版本不可变 | 仅 INSERT question_versions |
| 发布快照不可变 | exam_published_versions 只 INSERT |

---

## 5. 保留策略

- 考试、尝试、结果、题目版本、导入任务、审计：**5 年**逻辑保留，无 DELETE API。
- 导出文件、凭据包：**24 小时**过期（`expires_at`）。
