# 企业内部练习与考试系统

面向单一企业的内部练习与正式考试平台。管理员维护题库与考试，员工在同一身份下完成练习、模拟和正式考试，三端职责严格分离。

## 三端架构

- **员工小程序** — 练习、模拟、正式任务查看；不在小程序内正式作答
- **Web 正式考试端** — 桌面开卷、限时答题、自动保存、交卷与受控结果
- **Web 管理后台** — 组织/员工、题库/导题、考试发布/监控、成绩导出、审计
